# Hebrew Script Mode Classifier

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](
https://colab.research.google.com/github/TAU-CH/midrash_hebrew_script_mode_classifier/blob/main/Hebrew_Script_Mode_Classifier.ipynb
)

A deep learning based inferencer for classifying handwritten Hebrew document images as
square or non-square script. The interface also provides a heatmap evidence overlayed on the document image.

## Usage

1. Open the notebook in Google Colab.
2. Run the single startup cell.
3. Open the generated Gradio interface.
4. Upload a Hebrew manuscript image.
5. Prediction and attention visualization begin automatically.

## Output classes

- Square
- Non-square

## Input

A handwritten Hebrew document image.
